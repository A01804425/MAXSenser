# MAXSenser
Repositorio con documentación y codigo utilizado para el medidor de signos vitales. Desarrollado por los autores José Andrés Gutiérrez Muñoz y Sergio Antonio Foyo Puga. Medidor desarrollado con apoyo del microcontrolador ESP-WROOM-32, este utiliza sensores (véase la documentación para mas información) para medir temperatura, pulso, entre otros.
